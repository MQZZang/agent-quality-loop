# Distilled Principles

This is the human-readable synthesis of the bounded [claim ledger](claim-ledger.json), not a summary of all 13,040 PDF pages. Every principle below retains applicability, a failure condition, and an integration boundary.

| Principle | Use when | Do not use when / counterexample | AQL integration |
|---|---|---|---|
| Decompose only material dependencies | Later steps genuinely depend on earlier answers | A one-line edit becomes a multi-stage ceremony | Material L0–L10 compile layers, not a fixed questionnaire |
| Treat prompt components as an inspection aid | Missing facts, constraints, audience, or output criteria would change the result | Every task receives the same long schema | Alignment compiler checks only outcome-changing gaps |
| Separate fixed, guided, and open space | Hard constraints must survive while expert strategy remains delegated | All writers converge on one template | Alignment compiler and writing adapter preserve creative freedom |
| Curate context instead of maximizing it | A bounded source or profile item directly applies | The entire corpus/history is injected “just in case” | Version-bound `injected_refs` and context budgets |
| Separate fluency from truth | Real-world claims, citations, supplied facts, interpretations, or fictional passages matter | A creative premise is forced into a factual source map, or source handling is mislabeled as a truth mode | Four writing truth modes plus a separate source-handling axis |
| Model agreement is a probe, not evidence | Alternative drafts expose sensitivity or diversity | Repetition is treated as a citation or truth proof | No self-consistency acceptance oracle |
| Keep evaluation dimensions visible | Quality, collaboration cost, safety, and growth have different evidence | They collapse into one opaque score | Canonical acceptance dimensions; descriptive flywheel evidence |
| Current instruction outranks historical preference | A confirmed, context-matched preference helps execution | A past style choice overrides today's request | Same transparent profile, candidate/active/archived controls |
| Preference research does not authorize hidden optimization | Explicit preference/defaults can reduce repeated clarification | A ranker, bandit, embedding profile, or engagement reward silently steers work | No new recommender system or second event store |
| Skill availability is not skill value | Progressive disclosure makes a relevant domain rule accessible | Package size or installation count is advertised as outcome proof | Thin writing vertical plus behavior/runtime evidence |
| Mechanism success is not longitudinal growth | Static and runtime probes test current behavior | One good artifact proves the user became a better writer | Six-task pilot remains `NOT_RUN` |

The associated tensions, falsifiers, and rejected material are recorded in [contradiction-map.md](contradiction-map.md) and [rejected-material.md](rejected-material.md). Claim-specific source hashes, locators, counterevidence, grades, and copyright treatment remain authoritative in the JSON ledger.
