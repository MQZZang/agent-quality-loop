# Rejected or Non-Integrable Material

These are integration decisions, not deletion decisions. Source files remain unchanged.

| Material shape | Decision | Reason / re-entry condition |
|---|---|---|
| GitHub stars, install counts, “viral” or “popular” Skills | reject as product evidence | Popularity does not establish user outcome, safety, or writing quality. It may remain discovery metadata. |
| Public URL, arXiv hosting, or a successful download | reject as license proof | Reuse requires explicit license evidence; all current PDF license statuses remain unknown. |
| Chain-of-thought or model reasoning work presented as access to a user's brain, subconscious, personality, dopamine state, or left/right-brain type | reject | No selected evidence supports mind-reading or diagnostic authority. Re-enter only with task-relevant, falsifiable evidence and appropriate ethical scope. |
| Preference optimization used to justify a local hidden user reward/ranker | reject (C-010) | AQL lacks consented outcome labels, exposure coverage, offline evaluation, and rollback. Re-evaluate only if all are designed and evidenced. |
| Engagement, time-on-task, or repeated use as the primary reward | reject | It can reward dependency, friction, or manipulation rather than goal achievement or transferable ability. |
| One model judge or one self-consistency pass as an acceptance oracle | reject (C-006/C-007/C-013) | These can support a probe, never replace relevant firsthand evidence and counterexamples. |
| Whole-corpus runtime injection | reject (C-004) | It adds copyright, latency, relevance, and lost-in-context risk. Only version-bound applicable principles enter runtime references. |
| Fixed “viral writing” templates | reject | They collapse delegated strategy space, encourage unsupported persuasion claims, and create cross-task homogeneity. |
| Benchmark or static behavior success advertised as proven long-term writing growth | reject (C-008/C-012) | Longitudinal transfer requires real repeated tasks; current state is `NOT_RUN`. |
