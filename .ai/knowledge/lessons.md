# Lessons Learned

Verified, reusable experience from past agent sessions on this project. Not a chat log.

## Rules for This File

1. **Only verified lessons** — observed in repo, tests, or production; not speculation.
2. **No chat fluff** — no greetings, no duplicate narrative from tickets.
3. **No doc duplication** — if it belongs in README or official docs, link there instead.
4. **Update over append** — refine an existing entry rather than adding a near-duplicate.
5. **Propose first, write on confirmation** — agents may suggest a lesson in QA Next Step; do not write here unless the user asked or confirmed.

## Feedback Loop (from ask-plan-code-qa QA)

After verified implementation work, if a lesson is reusable:

1. Agent **proposes** an entry (title + one-line lesson) in QA **Next Step**.
2. User confirms or explicitly requests the write.
3. Agent adds entry using the template below; keep newest at top of **Lessons**.

## Entry Template

```markdown
### YYYY-MM-DD — Short title

**Context:** What task or area
**Lesson:** What we learned (one paragraph)
**Evidence:** PR, commit, test, or file path
**Applies when:** Trigger conditions for reuse
```
